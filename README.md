## Projects worth looking at

**[portainer_riscv64](https://github.com/isacS4nxx/portainer_riscv64)**
The only public Docker image of Portainer CE for `linux/riscv64`. Built from source, cross-compiled with QEMU, tested on an Orange Pi R2S with a RISC-V processor. Fully automated with GitHub Actions — builds and pushes to Docker Hub on every upstream update.
